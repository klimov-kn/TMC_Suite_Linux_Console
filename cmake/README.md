# CMake-инфраструктура

Здесь — общие настройки сборки (toolchain, флаги, опции), подключаемые корневым
`CMakeLists.txt`. Сама структура CMake появляется в Фазе 3 (см.
[../docs/build-linux.md](../docs/build-linux.md)).

## Заготовка плана

- корневой `CMakeLists.txt` (в корне проекта) — проект, `C++17`, `_PREC_DOUBLE`,
  подключение подпроектов `src/core`, `src/compat`, `src/cli`.
- здесь: при необходимости — модули поиска зависимостей, общие compile-опции,
  toolchain-файл для воспроизводимой сборки.

## Ключевые принципы (напоминание)

- Стандарт **C++17**, компилятор **g++ 13** (планка совместимости с Ubuntu 24.04).
- `_PREC_DOUBLE` — глобально (Баг #11).
- 6 макросов X-моды — только для цели `tmc_rtx` через `target_compile_definitions`,
  НЕ глобально и НЕ в заголовках.
- OpenMP — опционально, в пределах узла; MPI не используется.
