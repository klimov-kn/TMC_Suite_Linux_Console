# Форматы файлов TMC Suite

> Заказчик не смог ответить, бинарные форматы или текстовые (вопрос #17 — «не понял
> вопроса»). Разбираем сами по коду **SFILE95** и форматам ядер. Этот документ
> заполняется в Фазе 1–2 по результатам анализа `../TMC_Suite/src`.

## Зачем это нужно

Файлы должны быть совместимы с Windows байт-в-байт (#16). Чтобы это гарантировать,
надо точно знать структуру каждого формата: какие поля, какого типа, в каком порядке,
бинарь или текст, есть ли заголовок/версия. См. [binary-compat.md](binary-compat.md).
