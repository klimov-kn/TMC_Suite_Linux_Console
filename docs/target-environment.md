## Наше окружение для сборки

Доступа к серверу заказчика нет (#5), поэтому собираем и тестируем на **своей копии
той же системы** — Ubuntu 24.04 на VPS или локальной VM. Цель — добиться, чтобы
бинарник, собранный у нас, запустился у них без пересборки. См. [../env/README.md](../env/README.md).

### Почему важно совпадение версий

- **glibc.** Бинарник, слинкованный с новой glibc, не запустится на системе со
  старой: `GLIBC_2.XX not found`. Собирая на **той же Ubuntu 24.04**, мы задаём ту же
  планку glibc 2.39 — совместимость гарантирована.
- **g++ 13.** Используем тот же major-компилятор, чтобы стандартная библиотека C++
  (`libstdc++`) и ABI совпадали.

### Минимальная планка совместимости

Целевой стандарт: код должен собираться **g++ 13** под **C++17** (безопасный выбор;
C++20 доступен, но без необходимости не завязываемся). Не использовать фичи новее
g++ 13 и glibc 2.39.

### Развёрнутое окружение сборки (проверено 2026-06-24)

Поднято на **WSL2 (Ubuntu-24.04)**, хост Windows 11 Pro 22631. Версии тулчейна
сняты прямо из распакованного окружения и **совпадают с целевыми** — планка glibc
2.39 подтверждена не предположением, а фактом:

| Компонент | Версия | Совпадает с целью |
|---|---|---|
| Дистрибутив | Ubuntu 24.04.4 LTS (Noble) | ✅ |
| Архитектура | x86-64 | ✅ |
| g++ | 13.3.0 (`13.3.0-6ubuntu2~24.04.1`) | ✅ точное совпадение |
| cmake | 3.28.3 | — (инструмент сборки) |
| ninja | 1.11.1 | — |
| pkg-config | 1.8.1 | — |
| glibc (ldd) | 2.39 (`2.39-0ubuntu8.7`) | ✅ снимает неопределённость #2 |
| ядро (WSL2) | 6.18.x-microsoft-standard-WSL2 | n/a (своё у заказчика) |

> Развёртывание: `env/setup-ubuntu-24.04.sh`. Сетевой нюанс WSL2 (NAT не пускал
> apt наружу) решён `~/.wslconfig` → `networkingMode=mirrored`; детали в памяти
> проекта `wsl2-setup-state`.

## Что ещё запросить у заказчика (необязательно для старта)

Три команды с целевой машины снимут оставшуюся неопределённость:

```bash
cat /etc/os-release      # точный дистрибутив и версия
ldd --version            # версия glibc (потолок совместимости) — вопрос #2
g++ --version            # компилятор (уже знаем: 13.3.0)
uname -a                 # ядро и архитектура
```
