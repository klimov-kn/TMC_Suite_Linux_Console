# Слой совместимости (compat)

Весь код, который позволяет вычислительному ядру жить без Windows. Цель — собрать
здесь всю платформозависимость, чтобы `core/` оставался максимально чистым.

## Планируемое содержимое (Фаза 2)

- **`fixed_types.h`** — фиксированные по ширине типы для форматов файлов
  (`int32_t`/`int64_t` вместо `long`/`__int64`). Решает LP64/LLP64. См.
  [../../docs/binary-compat.md](../../docs/binary-compat.md).
- **win-заглушки** — определения оставшихся win-типов (`BOOL`, `DWORD`, `BYTE` и т.п.),
  если они встречаются в математическом коде вне MFC.
- **файловый IO** — обёртки чтения/записи вместо MFC `CFile`/реестра; бинарный режим,
  CP1251-поля как сырые байты.
- **потоки** — при необходимости адаптер Windows-потоков → OpenMP/`std::thread`.

## Правило

Любой `#ifdef _WIN32` и любая замена Windows-специфики должны жить **здесь**, а не
расползаться по `core/`.
