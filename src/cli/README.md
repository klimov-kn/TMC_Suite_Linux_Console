# Консольные точки входа

Две тонкие программы, заменяющие MFC-обёртку ядер: читают аргументы командной строки,
запускают расчёт из `core/`, возвращают код завершения.

## Планируемое содержимое (Фаза 4–5)

- **`tmc_rth_main.cpp`** — H-мода. `./tmc_rth <вход> <выход> [параметры]`.
- **`tmc_rtx_main.cpp`** — X-мода. Собирается с 6 макросами препроцессора (см.
  [../../docs/build-linux.md](../../docs/build-linux.md)).

## Что должна делать точка входа

1. Разобрать argv: входной файл, выходной файл, параметры расчёта.
2. То, что MFC-версия брала из окон/реестра, — получать из аргументов или конфиг-файла.
3. Вызвать вычислительное ядро (`core/`).
4. Сообщения об ошибках — в stderr (не окна `AfxMessageBox`); код возврата ≠ 0 при сбое.

## Принцип

Никакой математики и никакого GUI здесь нет — только запуск. Это сохраняет ядро
отделяемым, чтобы на этапе 2027 поверх него можно было поставить Qt-интерфейс.
