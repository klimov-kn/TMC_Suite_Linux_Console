# Исходники порта

## Принцип: математика общая с Windows, не дублируем

Источник истины по вычислительному коду — **`../TMC_Suite/src`**. Здесь мы НЕ форкаем
логику расчётов. Задача — обернуть ту же математику так, чтобы она собиралась g++ и
работала без Windows/MFC.

## Три слоя

| Папка | Что | Правила правок |
|---|---|---|
| [`core/`](core/) | Портированная **чистая математика** (PlanarRT_H/X, complex, prepr, TMCIndan, exprint, TMCLibError, sfile95) | Математику НЕ трогаем. Допустимо только: фикс. ширина типов в форматах файлов, замена win-типов на стандартные. |
| [`compat/`](compat/) | **Слой совместимости** — весь «клей» без Windows: фикс. типы для IO, файловый ввод-вывод вместо MFC/win32, заглушки оставшихся win-типов, CP1251-поля как байты | Здесь живут все `#ifdef`/замены. Свободно правим. |
| [`cli/`](cli/) | Две **консольные точки входа**: `tmc_rth` (H), `tmc_rtx` (X). Парсинг argv, запуск ядра, коды возврата — вместо MFC `InitInstance` | Новый код, пишем сами. |

## Как переносим код из Windows

1. Инвентаризация (субагент `linux-explorer`): что именно нужно ядрам, где MFC/win32.
2. Отделение математики от MFC (субагент `mfc-decoupler`).
3. Перенос нужных файлов сюда; правки компиляции — субагент `linux-porter`,
   каждую правку в `../ISSUES.md`.

⚠️ **Кодировка.** Перенесённые `.cpp/.h` из Windows — вероятно **CP1251**. НЕ
перекодировать, НЕ редактировать инструментом Edit (портит). Только PowerShell/Latin1
с ASCII-вставками. Новые файлы (compat/cli) — UTF-8.

## Граница «можно/нельзя»

- ✅ `long`→`int32_t` в сериализации (ширина формата), замена win-типов, замена
  Windows-потоков на OpenMP, удаление MFC.
- ❌ Формулы, константы, численные методы, порядок вычислений, `_PREC_FLOAT`.
